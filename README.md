# 헬스장 AI 경영비서 플랫폼 — MVP 1

기획서 v1.0의 **MVP 1 범위**를 구현한 Next.js 프로젝트입니다.
"AI부터 만들지 않는다"는 원칙에 따라, 먼저 정확한 회원·회원권·계약·매출·재등록 데이터가 쌓이는 시스템을 만들었습니다.

## 실행

```bash
npm run setup     # 의존성 설치 + DB 생성 + 데모 데이터 시드 (최초 1회)
npm run dev       # http://localhost:3000
```

| 계정 | 이메일 | 비밀번호 |
|---|---|---|
| 센터관리자 | admin@demo.gym | demo1234 |
| 트레이너(직원, 매출 열람 불가) | trainer@demo.gym | demo1234 |
| 슈퍼관리자 | super@platform.gym | demo1234 |

데모 데이터 초기화: `npm run db:reset`

## MVP 1 이후 추가된 기능

| 기능 | 설명 |
|---|---|
| 입구 키오스크 | `/kiosk/{token}` — 로그인 없이 휴대폰 뒷 4자리 입력 → 회원권 유효 확인 → 출석 기록(KIOSK). 설정 화면에서 링크 발급/재발급 |
| PT 차감 확인창 | "1회 사용" 클릭 시 "OOO님의 수업 1회를 차감하시겠습니까?" 확인 후 처리, "복원" 버튼으로 되돌리기 |
| 카카오 알림톡 자동 발송 | PT 차감 후 남은 횟수 + 응원 문구를 회원에게 발송. `/messages`에서 기록 확인 |

| AI 이벤트 포스터 (AI PRO) | `/events` — 이벤트 정보 입력 → Claude가 문구·색상·레이아웃 생성(키 없으면 템플릿) → 인스타 정사각/스토리/A4 포스터를 캔버스로 구성해 PNG 다운로드, 문구 복사 |
| 구독 · 결제 | 설정 상단 — 현재 요금제/다음 결제일, 요금제 변경(BASIC/SMART/AI PRO), 문자·카톡 크레딧 충전(보너스), 결제 내역. PG 키 없으면 테스트 결제 |

### AI 문구 생성 설정 (AI PRO)

`.env`에 `ANTHROPIC_API_KEY`를 넣으면 이벤트 생성 시 Claude(`claude-opus-5`)가 문구·색상·레이아웃을 생성합니다. 키가 없으면 규칙 기반 템플릿 문구로 동작합니다. AI는 입력한 혜택·기간·대상만 사용하고 가격이나 할인율을 지어내지 않도록 지시되어 있습니다.

### 결제(PG) 설정

`.env`에 `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`를 넣으면 실제 결제 모드로 전환할 수 있는 구조입니다(결제창 → confirm → `applyPlanChange`/`chargeCredits`). 키가 없으면 테스트 결제로 즉시 승인 처리되며 청구가 발생하지 않습니다. 실제 발송 모드에서는 메시지 1건마다 크레딧(알림톡 15원, SMS 20원, LMS 50원)이 차감되고, 잔액이 부족하면 발송이 실패로 기록됩니다.

### 카카오 알림톡 실제 발송 설정

기본은 **시뮬레이션 모드**(발송 내용만 기록)입니다. 실제 발송하려면 Solapi 계정과 카카오 비즈니스 채널을 연동한 뒤 `.env`에 다음 값을 넣습니다.

```
SOLAPI_API_KEY=...
SOLAPI_API_SECRET=...
SOLAPI_SENDER=01000000000          # 등록된 발신번호
KAKAO_PF_ID=...                    # 카카오 채널 ID
KAKAO_TEMPLATE_PT_REMAIN=...       # 검수 승인된 템플릿 ID
```

알림톡 템플릿은 카카오 검수를 통과해야 하며, 본문 변수는 `#{회원명} #{센터명} #{잔여횟수} #{총횟수} #{트레이너}`를 사용합니다. 템플릿 ID가 없으면 같은 내용이 SMS/LMS로 발송됩니다. 정보성 메시지는 알림톡 수신 동의, 광고성은 카카오 광고 동의를 검사해 미동의 회원은 자동 제외됩니다.

## 기술 구조

- Next.js 16 (App Router, Server Actions) + React 19 + TypeScript + Tailwind v4
- Prisma 6 + **SQLite** (로컬 개발). 운영 전환 시 `prisma/schema.prisma`의 `provider`를 `postgresql`로 바꾸고 마이그레이션 생성
- 인증: 이메일/비밀번호(bcrypt) + 서명된 JWT 세션 쿠키(jose)
- 전화번호: AES-256-GCM 암호화 저장 + HMAC 해시로 검색/중복검사 (`src/lib/crypto.ts`)
- 멀티테넌트: 모든 조회·변경이 세션의 `centerId`로 제한 (`src/lib/auth.ts`의 `requireCenterSession`)

```
src/
  app/(auth)/login, signup        로그인/센터 생성
  app/(app)/...                   센터 관리 화면 (사이드바 레이아웃)
  app/(public)/sign, survey       회원용 공개 페이지 (원격서명, 미재등록 설문)
  app/admin                       슈퍼관리자
  app/actions/*.ts                Server Actions (모든 쓰기 작업)
  lib/services/*.ts               도메인 로직 (회원 상태 계산, 재등록 추출, 통계, Import)
  components/                     UI, 폼, 서명패드, Import 마법사
prisma/schema.prisma              데이터 모델 (기획서 28장 기반)
prisma/seed.ts                    데모 데이터
```
